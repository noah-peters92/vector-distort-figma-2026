## About Vector Distort

Vector Distort expands Figma's standard transformation workflow with dedicated tools for reshaping artwork. The plugin provides mesh-based deformation, warp controls, and liquify-style adjustments for designers who need more than basic scaling and rotation.

Both vector layers and text objects can be edited through the plugin. This makes it suitable for exploring alternative compositions, producing custom visual treatments, and refining forms while staying inside the Figma desktop application.

---

## Features

- Edit shapes interactively with live mesh distortion
- Deform artwork using free-transform-style warping
- Apply organic changes with liquify brush tools
- Use algorithmic controls for consistent, repeatable distortion
- Modify underlying structure through Geometry mode
- Make layout-focused adjustments with Composition mode
- Support for vector layers
- Distortion workflows that include text objects

## Usage

A standard editing session looks like this:

1. Open a design file in Figma desktop.
2. Select one or more vector layers, or choose a text layer.
3. Run Vector Distort from the plugins menu.
4. Pick an editing approach, including mesh distortion, free-transform warping, or liquify-style brushing.
5. Continue adjusting the selected content until it fits the intended composition.

Duplicating an element before experimenting can make it easier to compare multiple distortion results before selecting the final version.
